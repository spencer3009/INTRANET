The user is building EduNet, a premium, multi-tenant SaaS application for schools in Peru. The project involves building out a full-featured student and owner portal. The immediate and primary goal is to completely overhaul the Horario de Clases (Class Schedule) module, transforming it from a basic card view into a professional, Google Calendar-style weekly grid.

**PRODUCT REQUIREMENTS (New Major Task):**
-   **Structure:** Create a weekly grid view with configurable hours on the Y-axis and days of the week on the X-axis.
-   **Configuration:** Add a settings modal (⚙️ icon) to allow school admins to define:
    -   Visible hour range (e.g., 07:00 to 22:00).
    -   Time format (12h/24h).
-   **Dynamic Grid:** The hour rows must be generated dynamically based on the configuration.
-   **Class Blocks:** Schedule entries should appear as colored blocks on the grid, showing subject, teacher, and classroom. Blocks should span multiple rows for longer classes.
-   **Add/Edit Modal:** The modal for adding a schedule entry must include fields for Course, Teacher, Day, Start Time, End Time, and an optional Classroom. The Course field must be a search-and-select combobox populated with subjects from the selected grade.
-   **Conflict Validation (Critical):** The backend must prevent creating or updating schedule entries that result in conflicts (e.g., the same teacher or classroom booked at the same time).
-   **Responsive Design:** The grid must be horizontally scrollable on smaller screens, with the time column remaining sticky.
